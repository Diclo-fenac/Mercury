┌──────────────────────────────────────────────────────────────────────────────┐
│ RRF ALGORITHM                                                                │
└──────────────────────────────────────────────────────────────────────────────┘

Formula:
  RRF_score(d) = Σ (weight_i / (k + rank_i(d)))
  
  where:
    d = document/product
    k = 60 (standard constant)
    rank_i(d) = rank in source i
    weight_i = source weight

Example:
  Product in both sources:
    Typesense: rank=3, weight=0.6 → 0.6/(60+3) = 0.00952
    RRF score: 0.00952

  After reranking:
    User prefers category: +20% → 0.01930
    Product rating 4.5:    +27% → 0.02451
    Final score: 0.02451

│ QUICK START                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1. Setup Typesense:
   $ ./scripts/setup_typesense.sh

2. Configure .env:
   TYPESENSE_HOST=localhost
   TYPESENSE_PORT=8108
   TYPESENSE_API_KEY=xyz

3. Index products:
   $ python scripts/index_typesense.py

4. Test system:
   $ python scripts/test_search.py

5. Start app:
   $ python main.py

6. Test search:
   $ curl -X POST http://localhost:8000/api/v1/search/ \
     -H "Content-Type: application/json" \
     -d '{"query": "laptop", "user_id": "test"}'
